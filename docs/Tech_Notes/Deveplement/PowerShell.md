PowerShell has a strict list of “approved verbs” for function names.
PowerShell wants function names to follow:

Code

```
Verb-Noun
```

And the **verb** must be one of the approved verbs like:

- Start
    
- Stop
    
- Get
    
- Set
    
- Invoke
    
- New
    
- Remove
    
- Test
    
- Convert
    
- Write
    
- Read
    
- Update
    
- Backup
    
- Restore
    
- Sync
    
- Split
    
- Merge
    
- Compress
    
- Expand
