The Best Order to Install

1. **First, download and install [Ollama](https://www.google.com/goto?url=CAESSwHrOzAVe518Yj5fv0NnuzRovVmpmrTo1DKPfNviv9eejoKC5G_QHf7NOQTxnykWnUAQlH_F8M7Lx9EoPGG5nWjtQb3NhTgQJgDdlA)**

        `ollama run llama3.1` (or your chosen Qwen/Gemma model).
    - Test it with a quick message in the terminal to confirm it works, then close the terminal. Ollama will keep running silently in your system tray.
2. **Second, download and install [AnythingLLM Desktop](https://www.google.com/goto?url=CAESUAHrOzAVgDSP9-BnZG3aGPZB1PKTWYOH6WcrtX_tqfuOWDxq35bmBajEdWDp-Y55d8lv8UJKFTr6unumLypHx0XxPUyh_SxJThYP0RCedpLg)**
    - Install the desktop application.
    - When you launch AnythingLLM for the first time, it will walk you through a setup wizard and ask: _"Which LLM provider would you like to use?"_
    - Select **Ollama** from the list. Because Ollama is already running on your machine, AnythingLLM will automatically detect it and instantly display a list of all the models you downloaded in Step 1.

⚙️ How They Run Side-by-Side

Once configured, they live in perfect harmony on your computer:

- **Zero Connection Effort:** Every time you open AnythingLLM in the future, it automatically talks to Ollama in the background. You don't need to manually configure any complicated network addresses.
- **The Workflow:** You will use AnythingLLM's window to create workspaces, click a button to upload your private files, and chat with the AI. Behind the scenes, AnythingLLM safely sends the text over to Ollama to process the data entirely on your graphics card or RAM.
